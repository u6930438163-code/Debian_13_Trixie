TWOJE CENTRUM DOWODZENIA

Rozmowy z agentami AI

Wybierz oryginalnego agenta. Połączenie jest weryfikowane przez API.

„Wszyscy” wymaga rzeczywistej bramy wiadomości między oryginalnymi agentami. Wysyłanie jest chwilowo zablokowane, żeby nie udawać czatu grupowego.
W czym mogę pomóc? Wybierz profil i wyślij wiadomość. /help działa lokalnie, /cli pwd przekazuje polecenie do terminala; pozostałe wiadomości wymagają dostępnego modelu.

Wiadomość zostanie wysłana po połączeniu z API.

RZECZYWISTE ZADANIA API

Work

Work połączy się z API po otwarciu widoku.

Dodaj zadanie do kolejki

Zadanie trafia do przypisanego agenta. Jeśli agent ma skonfigurowany model, przejmuje je samodzielnie w tle — bez roli i bez skryptu, tylko z treścią zadania — a jego odpowiedź pojawia się w kolejce. Agent nie wykonuje poleceń powłoki, nie zmienia plików, nie dostaje roota i nie robi zakupów.

Oryginalny Alex: oczekuje na sprawdzenie możliwości wysyłania zadań. Przekazanie polecenia nie oznacza zakończenia pracy.
