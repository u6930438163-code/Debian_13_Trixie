TWOJE CENTRUM DOWODZENIA

Rozmowy z agentami AI

Wybierz oryginalnego agenta. Połączenie jest weryfikowane przez API.

„Wszyscy” wymaga rzeczywistej bramy wiadomości między oryginalnymi agentami. Wysyłanie jest chwilowo zablokowane, żeby nie udawać czatu grupowego.

Wybierz profil i wyślij wiadomość. /help działa lokalnie; pozostałe wiadomości wymagają dostępnego modelu.

Wiadomość zostanie wysłana po połączeniu z API.

RZECZYWISTE ZADANIA API

Work

Work połączy się z API po otwarciu widoku.

Zadania są trwale zapisywane w API do przeglądu. Wysłanie zadania NIE uruchamia agenta AI, nie wykonuje kodu i nie zatwierdza zakupów. Każdy etap wykonania wymaga osobnego, rzeczywiście działającego workera.

POLECENIA OGRANICZONEGO API

Terminal

pwd · ls · cat

To nie jest powłoka systemowa. Polecenia są walidowane i obsługiwane przez API.

Gotowy · polecenia tylko do odczytu

Dozwolone są wyłącznie pwd, ls oraz cat <plik> w katalogu roboczym.

Obsługiwane są tylko pwd, ls i cat <plik> w katalogu roboczym.

PYTHON · INTERAKTYWNE

Skrypty diagnostyczne

Izolowane · bez root

Wybierz dozwolony skrypt. Otrzymasz rzeczywiste pytanie z backendu i wpiszesz odpowiedź. Dowolny kod Python pozostaje zablokowany.

Nie uruchomiono żadnego skryptu.
