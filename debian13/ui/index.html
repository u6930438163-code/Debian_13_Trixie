NIEZALEŻNE ŚRODOWISKO DEBIAN 13

W czym mogę pomóc?

Wiadomości są wysyłane do lokalnego API. Odpowiedź modelu pojawi się tylko wtedy, gdy Ollama jest dostępna.

Wybierz profil i wyślij wiadomość. /help działa lokalnie; pozostałe wiadomości wymagają dostępnego modelu.

Wiadomość zostanie wysłana po połączeniu z API.

RZECZYWISTE ZADANIA API

Work

Work połączy się z API po otwarciu widoku.

POLECENIA OGRANICZONEGO API

Terminal

pwd · ls · cat

To nie jest powłoka systemowa. Polecenia są walidowane i obsługiwane przez API.

Dozwolone są wyłącznie pwd, ls oraz cat <plik> w katalogu roboczym.

Obsługiwane są tylko pwd, ls i cat <plik> w katalogu roboczym.
